Always query `MODULE` nodes using `file_path` attribute with `ENDS WITH` or `CONTAINS` if the full path is uncertain.
2. **Directory Queries**: When asked for all files/modules in a directory (e.g., `src/foo/bar/`), use `CONTAINS` on the `file_path` attribute. Do not restrict the node label to `MODULE` as some files might be represented by other nodes or you may need to retrieve functions/classes directly.

3. Use nodes `MODULE`, `FUNCTION`, `STRUCT`, `FIELD`, `MACRO`, etc., and relationships like `CONTAINS`, `DECLARES`, `DEFINES`, `USES`, `INHERITS`.
4. CRITICAL: The database stores relative paths (e.g., `src/main.c`). If the input contains an absolute path (e.g., `E:\project\src\main.c`), NEVER use equality (`=`). ALWAYS use `ENDS WITH` and normalize separators to forward slashes.
