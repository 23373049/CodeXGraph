#### Detailed Comment Notes:
Each function comment should include:
1. **Brief Description**: One or two sentences describing the function's responsibility.
2. **@param entries**: One per argument, specifying purpose, expected range, pointer direction (in/out), and ownership if relevant. If the function has no parameters, omit the section.
3. **@return/@retval**: Describe the return value or state explicitly; if the function returns `void`, include `@return void`.
4. **@note/@warning (optional)**: Mention side effects, required preconditions, or error scenarios.

Example format:
```c
/**

 *
 * @return int 0 on success, negative errno-style code on failure.
 * @note This call configures GPIO pins and clocks as a side effect.
 */
```
